# Hana Proactive

让 Hana 在用户长时间未回复时能主动开口。插件负责检测时机，Agent 负责说话内容。

## 工作方式

插件后台定时器周期性检查条件。发送间隔随连续未回复次数递增（15min → 30min → 60min → 120min），超过最大次数后自动静默。

Agent 看到 `__proactive__` 标记消息时，就是该说话的时候。

## 设置方式

两种途径都可调节：

**设置面板**（原生配置界面）：在插件管理中找到 Hana Proactive，进入设置。

**对话中自然语言**：
- "别吵我" → 切换到 low
- "陪我聊会" → 切换到 high
- "就按默认" → 切回 medium

Agent 听到后调用 `proactive_setup` 更新，并口头确认。

## Agent 开口指南

### 听到信号后

1. 查看当前时间
2. 自由调用工具获取上下文（日历、待办、或任何已接入的数据源）
3. 根据拿到的信息自然开口
4. **不要提**"检测到你很久没说话"

### 语气参考

| 情境 | 示例 |
|------|------|
| 有待办快到期 | "你那个 xxx 是不是今天要交？" |
| 有日程即将开始 | "半小时后有会" |
| 无特别事项 | 轻触式，参考最近话题 |
| 深夜 | 更轻，或沉默陪伴 |

## 标记对话结束

当用户表达结束意图时（"晚安"、"先这样"、"下次聊"），调用 `proactive_mark_ended` 停止主动触发。之后用户再来时调用 `proactive_resume` 恢复。

## 工具清单

| 工具 | 用途 |
|------|------|
| `proactive_setup` | 配置存在感级别 |
| `proactive_record_activity` | 每次用户发消息后调用 |
| `proactive_check` | 备用手动检查 |
| `proactive_mark_ended` | 对话结束时调用 |
| `proactive_resume` | 恢复主动检测 |
